What this does and does not show

Shows: the software reads real PSG, stages sleep, measures features, learns latent features without labels, and its statistical tests behave correctly (about 5% false positives, planted effects found, no train/test leakage). Does not show: any link between these features and anxiety, or performance in people with MCI/SCI. That requires the clinicians' labelled cohort (Validation 4). Sleep-EDF has no ECG, so the HRV module was checked on reference signals; repeat V1b on HMC recordings.
